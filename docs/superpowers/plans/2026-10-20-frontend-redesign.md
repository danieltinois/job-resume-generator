# Frontend Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the Angular app the approved SaaS look (emerald on zinc, Inter, sidebar shell, light/dark/system) plus empty states, skeletons, shortcuts and job search, without changing what the app does.

**Architecture:**
- Our own CSS tokens (`light-dark()`) are the source of truth, and Angular Material is themed and overridden to read them.
- Two route-level layouts (`AuthLayout`, `AppShell`) replace the toolbar.
- Small shared pieces under `app/ui/`, plus `Theme` and `Shortcuts` services under `app/core/`, are then applied screen by screen.

**Tech Stack:**
- Angular 22.2 (standalone, OnPush, signals), Angular Material/CDK 22.2.
- Vitest (Angular unit-test builder).
- Playwright 1.64 with `@axe-core/playwright` (new dev dependency).
- Inter and Material Symbols Outlined from Google Fonts.

**Spec:** `docs/superpowers/specs/2026-10-20-frontend-redesign-design.md`

## Global Constraints

- **Tokens:**
  - The colour tokens and their light/dark values are exactly those of spec §3, named `--app-bg`, `--app-surface`, `--app-subtle`, `--app-border`, `--app-border-strong`, `--app-text`, `--app-muted`, `--app-accent`, `--app-on-accent`, `--app-accent-soft`, `--app-on-accent-soft`, `--app-warn-soft`, `--app-on-warn-soft` and `--app-danger`.
  - Each is defined once with `light-dark(<light>, <dark>)` on `:root`.
- **Type:** Inter 400/500/600; base 14 px / 1.5; page titles 24 px / 600 / letter-spacing -0.02em; `tabular-nums` on dates, counts and scores.
- **Shape and size:**
  - Radius 8 px on buttons and inputs; 12 px on cards, panels, menus and dialogs; 999 px on chips, pills and avatars.
  - Controls are 40 px high; icon buttons at least 36 px with a 40 px hit area.
  - Focus ring: 2 px `--app-accent` outline, 2 px offset.
- **Motion and icons:** transitions 150 ms ease, and none under `prefers-reduced-motion: reduce`; icons are Material Symbols Outlined, weight 300, 18–20 px.
- **Theme:** the choice is stored in `localStorage` key `ui-theme` (`'light' | 'dark' | 'system'`, default `'system'`), inside try/catch.
- **No server or policy changes:** no backend, API or CSP change; no inline `<script>`; illustrations are inline SVG.
- **Unchanged contracts:** routes, paths, guards and the unsaved-changes guard keep their behaviour; existing `data-test` hooks keep their names.
- **Text:** every new UI string goes into both `core/i18n/pt.ts` and `core/i18n/en.ts`.
- **Repo rules:** AGENTS.md applies: components standalone + OnPush + signals; no test skipped; commits authored as the owner, Conventional Commits, no trailers.

## Review Focus

1. **A stored theme value that is not `light`/`dark`/`system`, or a `localStorage` that throws.** The app should fall back to `system` and not crash. Test in Task 2.
2. **Plain-key shortcuts while typing.** `N` or `/` in the job search, a chip input, the description textarea or a contenteditable element must not trigger; neither should they while a dialog is open. Ctrl/⌘ combos still work. Test in Task 4.
3. **Search input variety:** mixed case, accents ("sao" matches "São", "dados" matches "Dados"), surrounding spaces, and a query that only has spaces. A blank query shows every job. Test in Task 7.
4. **Phone width:**
   - the navigation must open as an overlay;
   - Esc must close it;
   - choosing a link must close it;
   - the user menu (theme, language, sign out) must stay reachable.

   Test in Task 5.
5. **A very long job title or company.** It must truncate in the row without pushing the actions off-screen, with the full text still available (a `title` attribute). Test in Task 7.
